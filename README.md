# CodeIgniter 4 Quiz Reviewer

A minimalist, cookie-colored quiz reviewer covering Modules 1–4 (routing, MVC, models, forms and uploads, sessions and authentication).

- **Reviewer:** Previous/Next buttons, a question grid on the right, and instant feedback with correct answers in bold.
- **Challenge:** a separate mode with only Previous/Next; results are shown after you finish.

## Files
- `index.html` – page structure
- `style.css` – cookie palette (light and dark)
- `script.js` – questions and quiz logic

## Run locally
Open `index.html` in a browser. No build step or server needed.

## Publish on GitHub Pages
1. Push these files to a repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save, and your site will be live at `https://<username>.github.io/<repo>/`.
